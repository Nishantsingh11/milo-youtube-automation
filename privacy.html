Privacy Policy — Milo YouTube Automation

Last updated: 28 October 2026. Contact: ns115047@gmail.com
App: Milo YouTube Automation. Owner: Nishant Singh.

This policy describes how this app accesses, uses, stores, and shares Google user data.

What this app is

Milo YouTube Automation is a personal automation tool for the owner's own YouTube channels (Milo the Cat - Kids Songs, Milo Counts - Kids Numbers, Milo Colours - Kids Colours, Milo Hindi Rhymes). It uploads short cartoon videos that the owner has already made, on a schedule the owner set. It is not a public service and it does not serve other users.

Google user data this app accesses

Only two YouTube Data API v3 scopes are requested:

  • https://www.googleapis.com/auth/youtube.upload — "Manage your YouTube videos"
  • https://www.googleapis.com/auth/youtube.readonly — "View your YouTube account"

No Gmail, Drive, Contacts, Calendar, or profile scopes are requested. The app does not read comments, subscribers, analytics, or watch history.

How that data is used

  • youtube.upload: to upload a video file the owner provides, with the title, description, tags, category, privacy status, and Made for Kids flag the owner set, to the channel the owner authorised.
  • youtube.readonly: to list the owner's channels before an upload, so the upload goes to the channel the owner actually authorised, and to confirm the uploaded video's privacy status afterwards. It is not used for any other purpose.

How data is stored

OAuth access and refresh tokens are stored only as files on the owner's private virtual machine, with file permissions restricted to the owner (chmod 600). They are never pasted into chat, email, or any public page. Video files, titles, and descriptions are the owner's own content, stored on the same machine. No Google user data is stored on any third-party server, analytics service, or advertising service.

Sharing

This app does not sell, share, or disclose Google user data to any third party, for any purpose. The only external service contacted is Google's YouTube Data API itself, to perform the upload and the channel check above.

Revocation and deletion

The owner can revoke access at any time from Google Account > Security > Third-party access > Milo YouTube Automation. Revocation stops all future uploads immediately. On revocation, or on request to ns115047@gmail.com, stored tokens are deleted from the machine. Deletion is completed within 30 days of revocation or request, and usually immediately on revocation. Uploaded videos themselves remain on YouTube under the owner's control and are managed from YouTube Studio, as with any video.

Changes to this policy

If this policy changes in a way that affects how Google user data is used, the change will be published here before the new use begins.
